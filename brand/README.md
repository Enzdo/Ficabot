# Logos de marque

Déposez ici les fichiers du logo Ficana, puis prévenez-moi : je les copie
dans le `public/` des trois applications et je câble les composants.

## Fichiers attendus

| Nom                      | Usage                                              |
|--------------------------|----------------------------------------------------|
| `ficana-logo.svg`        | Blason complet, fond clair (idéal : SVG)           |
| `ficana-logo-dark.svg`   | Blason complet, fond sombre (texte crème)          |
| `ficana-mark.svg`        | Marque simplifiée, sans texte, pour les petits usages |

À défaut de SVG, des PNG à fond transparent de 1024 px de large conviennent
(`.png` au lieu de `.svg`).

## Pourquoi une marque simplifiée en plus

Le blason contient deux animaux gravés, du feuillage et le mot-symbole.
À 36 px dans une barre latérale ou 32 px en favicon, l'ensemble devient une
tache illisible. Le blason sert donc aux grandes surfaces (accueil, pied de
page, panneau d'authentification) ; la marque simplifiée sert aux petits
formats.
